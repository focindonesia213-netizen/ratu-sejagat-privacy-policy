1. Pendahuluan

Selamat datang di Ratu Sejagat (Package ID: com.foc.ratusejagat), sebuah game teka-teki logika penempatan mahkota. Kebijakan Privasi ini menjelaskan komitmen tegas pengembang (FOC Indonesia) dalam melindungi privasi seluruh pengguna kami.

Prinsip Utama: Privasi Anda adalah prioritas mutlak kami. Game ini dirancang secara berprinsip privasi tinggi (Privacy by Design) — kami sama sekali tidak mengumpulkan, menyimpan, atau membagikan informasi pribadi apa pun dari pengguna.

2. Batasan Usia Pengguna (13 Tahun ke Atas)

Game Ratu Sejagat ditujukan secara khusus untuk pengguna yang berusia 13 tahun ke atas (atau batas usia kedewasaan digital minimum di wilayah hukum Anda).

  • Game ini tidak dirancang secara khusus untuk anak-anak di bawah usia 13 tahun.
  • Kami tidak secara sengaja atau tidak sengaja mengumpulkan data pribadi apa pun dari siapa pun, termasuk anak-anak di bawah usia 13 tahun.
  • Apabila Anda adalah orang tua atau wali dan memiliki pertanyaan mengenai aplikasi ini, Anda dapat menghubungi kami kapan saja.

3. Informasi yang Kami Kumpulkan: NIHIL

Kami menegaskan bahwa kami TIDAK MENGUMPULKAN DATA PRIBADI APAPUN, termasuk namun tidak terbatas pada:

  • Data Identitas: Nama, alamat, nomor telepon, alamat email, atau akun media sosial.
  • Data Lokasi: Lokasi GPS, jaringan seluler, atau alamat IP yang tersimpan.
  • Pengenal Perangkat: IMEI, Android ID, MAC address, atau Advertising ID.
  • Data Keuangan: Tidak ada transaksi uang asli, tidak ada langganan, dan tidak ada pengumpulan data kartu kredit/debit.
  • Data Penggunaan / Analitik: Kami tidak melacak durasi bermain, kebiasaan mengetuk layar, atau aktivitas dalam game Anda ke server mana pun.

4. Penyimpanan Data Lokal di Perangkat Pengguna

Semua progres permainan (level yang telah diselesaikan, preferensi tema, pengaturan suara, dan kustomisasi mahkota) disimpan secara 100% lokal di dalam memori penyimpanan perangkat Anda sendiri menggunakan basis data internal berkecepatan tinggi (Hive).

  • Data lokal ini tidak pernah dikirimkan, disinkronkan, atau diunggah ke server cloud mana pun.
  • Jika Anda menghapus instalasi (*uninstall*) game atau membersihkan data aplikasi melalui pengaturan Android, semua riwayat progres permainan akan terhapus secara otomatis dan permanen dari perangkat Anda.

5. Iklan dan Layanan Pihak Ketiga

Game Ratu Sejagat berkomitmen memberikan pengalaman bermain murni tanpa gangguan:

  • Bebas Iklan (No Ads): Tidak terdapat banner iklan, video berhadiah (*rewarded ads*), maupun iklan pop-up (*interstitial*).
  • Bebas SDK Pihak Ketiga: Kami tidak mengintegrasikan SDK analitik pihak ketiga (seperti Firebase Analytics, Google Analytics, Facebook Pixel, dll.) yang dapat melacak jejak digital Anda.

6. Izin Perangkat (Permissions)

Game ini beroperasi secara mandiri dan tidak memerlukan izin khusus yang sensitif, seperti akses kamera, mikrofon, kontak, penyimpanan file eksternal, atau lokasi GPS.

7. Hak Privasi dan Penghapusan Data

Karena kami tidak mengumpulkan data pribadi apa pun di server kami, Anda memegang kendali penuh 100% atas data game Anda:

  • Anda dapat mereset data permainan kapan saja melalui menu Settings di dalam aplikasi, atau
  • Menghapus data melalui menu Pengaturan Android > Aplikasi > Ratu Sejagat > Hapus Penyimpanan (Clear Storage).

8. Perubahan pada Kebijakan Privasi

Kami dapat memperbarui Kebijakan Privasi ini dari waktu ke waktu jika terdapat pembaruan fitur pada game. Setiap perubahan akan segera dipublikasikan secara transparan di halaman ini.

We expressly declare that we DO NOT COLLECT ANY PERSONAL DATA, including but not limited to:

Because we do not collect or store any personal data on external servers, you retain complete 100% control over your game data:
